**Hardened backend.** The API and ingestion worker now build, migrate and boot. Tenant isolation is enforced by Postgres, and the resilience ladder keeps its promise: every question gets an answer and a recorded reason. The console arrives in v1.0.0.

## Highlights

- **Real tenant isolation**
  - The app connects as the `omniio_app` role (not the owner, not a superuser, `NOBYPASSRLS`).
  - Every unit of work is a short transaction that sets `app.workspace_id` transaction-locally, and refuses to run without one.
  - Policies use `nullif(...)`, so reused pooled connections don't hit the empty-string `''::uuid` error.
  - Pre-tenant lookups go through four narrow `SECURITY DEFINER` functions.
  - All of this is proven by an integration suite against real Postgres.
- **The ladder never throws**
  - An embedding or database outage goes to the FAQ floor, not a 500.
  - The model call has a hard timeout and a circuit breaker.
  - Output is schema-validated, and every citation must be a passage that was actually sent.
  - Confidence and similarity thresholds are per workspace.
  - Every answer carries a decision trace. Audit writes are fire-and-forget and record the tokens of rejected Tier 1 attempts.
- **Gemini provider** (`gemini-3.5-flash`, `gemini-embedding-2` at 768 dimensions) behind a small interface, plus a deterministic **fake provider** with failure markers (`[fail:error]`, `[fail:timeout]`, …) for tests and demos.
- **Ingestion worker** runs as its own process:
  - retries with backoff
  - status tracking (`pending → processing → ready | failed`)
  - live progress over a GraphQL subscription
  - batched embeddings and idempotent replacement of stale chunks
  - jobs that carry ids only, so erasure leaves nothing in Redis
- **Auth**
  - 15-minute access tokens.
  - Opaque, rotating refresh tokens in an httpOnly cookie, with reuse detection.
  - Live role checks against the membership table.
  - No granting above your own role; the last owner is protected.
  - Google sign-in with PKCE.
- **Full API surface**
  - GraphQL for workspaces, members, documents, FAQs, ladder settings, the audit log and the widget.
  - Multipart upload (PDF/TXT/MD ≤ 20 MB).
  - GDPR erasure.
  - Widget key rotation.
  - Redis-backed rate limits.
  - MCP over Streamable HTTP, scoped to the caller.

## Breaking changes from 0.1.0

- Drizzle is removed. Migrations are plain SQL in `backend/migrations/`, run with `npm run migrate` as `DATABASE_MIGRATOR_URL` (the owner).
- `DATABASE_URL` must now be the `omniio_app` role. `docker-compose` creates it for local development.
- The widget config endpoint moved from `GET /w/:key` to `GET /w/:key/config`.
- Configuration is validated at boot. See `backend/.env.example`.
